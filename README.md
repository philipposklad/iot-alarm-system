# IoT Alarm System

A low-cost IoT-enabled alarm system based on the ESP8266, combining autonomous
local operation with remote control, monitoring, and cloud notifications.

The system was originally developed as part of my undergraduate thesis and was
later used as a practical case study in a peer-reviewed conference publication.

## Overview

The project implements a complete alarm-system prototype integrating embedded
control, conventional 12 V alarm hardware, local user interaction, and IoT
connectivity.

A NodeMCU (ESP8266) acts as the central controller and manages sensor inputs,
alarm outputs, keypad interaction, system state, timing, and communication with
the Arduino IoT Cloud.

The system is designed to remain operational locally without depending on an
Internet connection. At the same time, the IoT interface provides convenient
remote control, system monitoring, and event notifications through a mobile
device.

## Key Features

- Autonomous local alarm operation
- Remote alarm control through Arduino IoT Cloud
- Remote sensor monitoring
- Push and email event notifications
- 3×4 local keypad interface
- Analog keypad decoding using a single ADC input
- Multiple configurable sensor inputs
- Pre-alarm and main alarm outputs
- State-based alarm control logic
- Electrical isolation between controller and 12 V alarm circuitry
- Battery-backed prototype implementation
- Modular object-oriented C++ firmware

## System Architecture

The system combines four principal layers:

**Sensors / Keypad → Embedded Controller → Alarm Outputs**

with bidirectional cloud connectivity:

**Embedded Controller ↔ Arduino IoT Cloud ↔ Remote User Interface**

The embedded controller executes the fundamental alarm logic locally, while the
cloud platform extends the system with remote control, monitoring, and
notifications.

## Hardware

The prototype integrates a NodeMCU ESP8266 with conventional 12 V alarm
components.

The hardware design includes:

- LM317-based voltage regulation
- Optocoupler isolation
- Transistor-based output stages
- 12 V alarm peripherals
- Backup battery
- 3×4 analog keypad interface
- Multiple sensor inputs
- Pre-alarm and main siren outputs

The keypad interface uses a resistor network to generate a different analog
voltage for each key, allowing all twelve buttons to be decoded through a
single ADC input.

Detailed hardware documentation, schematics, and the bill of materials are
available in the [`hardware/`](hardware/) directory.

## Firmware

The firmware was developed in C++ using the Arduino development environment.

The implementation follows an object-oriented structure with dedicated
components for:

- `microcontroller` — central system coordination and alarm logic
- `sensor` — sensor monitoring and behavior
- `siren` — audible output control
- `keypad` — analog keypad decoding and local user input

The high-level alarm behavior is implemented using state-based control logic,
while cloud-synchronized variables connect the local system with the remote
interface.

See [`firmware/`](firmware/) for the source code and firmware documentation.

## IoT Remote Control and Monitoring

Arduino IoT Cloud provides the remote interface for the system.

The configured mobile dashboard allows the user to control supported alarm
functions, monitor sensor states, and receive notifications generated by sensor
and alarm events.
